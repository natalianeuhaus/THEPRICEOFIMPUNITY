# Regional mining-frontier sequence (Chapter 2)

`2012.webp` through `2026.webp` are representative frames extracted from
the project's separately stored
`Madre_de_Dios_Mining_Frontier_2012-2026_Regional_Timelapse.gif`.
They share the same illustrated
extent covering Huepetuhe, Delta Uno, La Pampa, the Pariamanú River, and
Puerto Maldonado. The sequence is designed as visual context, **not** as
individually verified, georeferenced annual satellite classifications.

The 2026 frame includes stylized outlines from the Amazon Mining Watch /
Earth Genome model. The separate Leaflet overlay in `../../index.html` uses
the project GeoJSON derived from the published mining-detection raster and
provides source-linked, clickable records. Its outlines are not proof that a
given site is illegal or that the shapes describe the exact annual footprint.

For future scientific year-over-year comparison, replace these frames with
verified annual Landsat composites at one documented extent, with year-specific
cloud masks, acquisition dates, processing methods, and provenance.
